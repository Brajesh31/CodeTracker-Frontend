# 📖 Glossary

| Term | Meaning in this repository |
| --- | --- |
| Auth state | Current Firebase Authentication user state observed by the React app |
| Browser SPA | A client-rendered single-page application served as static web assets |
| CodeTracker | The frontend product name used in this repository |
| Firestore | Cloud Firestore database accessed through the Firebase browser SDK |
| Firebase UID | Stable identifier assigned to a Firebase Authentication user |
| Hosting rewrite | Firebase Hosting rule that serves index.html for browser routes |
| Question document | A Firestore document in the questions collection rendered by the dashboard |
| Vite variable | Build-time environment variable accessed through import.meta.env |
| VITE_ prefix | Prefix that makes a variable available to client-side Vite application code |
| Security Rules | Firebase-side rules that authorize data access; not included in this repository today |
| Synthetic data | Test records that do not contain real user information |
| SPA entry point | leetcode/index.html, which loads the React bootstrap module |
| Companion extension | The separately distributed browser extension linked by the landing page; its source is not in this repository |
| Source-derived schema | A description inferred from field access in code, not a formally validated database contract |
| CI | Automated validation executed on repository changes |
| CD | Automated deployment after configured validation and authorization |

Use consistent terminology in issue titles, documentation, code comments, and support answers. Avoid calling the current question list a question editor or calling the current UID filter authorization.

# 📸 Application Screenshots

This folder is reserved for screenshots captured from the real CodeTracker application running against a development Firebase project with synthetic data.

## Capture requirements

- Capture the current implementation, not a proposed or redesigned interface.
- Use synthetic account names and question records.
- Remove email addresses, Firebase identifiers, tokens, browser profile data, and other personal information.
- Record the app commit SHA, browser, viewport, and route alongside each screenshot.
- Use descriptive filenames such as landing-desktop.png or dashboard-mobile.png.
- Add meaningful alt text and reference the image from README.md or the relevant page guide.
- Refresh screenshots whenever the UI changes materially.

No screenshots are included yet because there is no verified capture from a running application in this repository review. SVG architecture illustrations are stored in the parent assets directory and are not presented as application screenshots.

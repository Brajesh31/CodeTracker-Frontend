# 🆘 Support

## Get help

Start with the [Documentation Hub](docs/README.md) or the most relevant guide:

- [Installation](docs/installation.md) for Node/npm setup and Firebase client configuration.
- [Troubleshooting](docs/troubleshooting.md) for development, authentication, data, and Hosting issues.
- [FAQ](docs/faq.md) for current feature boundaries and common questions.
- [Project Status](docs/project-status.md) and [Known Issues](docs/known-issues.md) for verified limitations.
- [Security Policy](SECURITY.md) for private vulnerability reports.

## Report a bug or request a feature

Search existing GitHub issues and open a new issue in [Brajesh31/CodeTracker-Frontend](https://github.com/Brajesh31/CodeTracker-Frontend/issues). Select the appropriate bug, feature, documentation, accessibility, or performance template.

For a useful report, include:
- Browser and operating-system versions.
- The route, component, command, or workflow involved.
- Steps to reproduce.
- Expected and actual behavior.
- Sanitized logs or screenshots, when useful.

Remove access tokens, email addresses, user records, and other private data from logs and screenshots. Never post Firebase credentials or service-account files.

## General questions

Use GitHub Discussions if enabled, or a relevant issue when the answer will help other contributors. Read the docs first and include enough context to reproduce the question.

## Firebase account and deployment help

The maintainer of this source repository may not control your Firebase project, Microsoft Edge extension listing, external study-resource site, or account. For access and billing issues, contact the owner of the relevant service. Do not post Firebase credentials or user data in public support channels.

## Support expectations

This is a volunteer-maintained project. No response-time guarantee, uptime commitment, or paid support channel is offered.

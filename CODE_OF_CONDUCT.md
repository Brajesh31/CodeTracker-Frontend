# Code of Conduct

## Our commitment

The CodeTracker project welcomes contributions from people with different backgrounds and levels of experience. We want project discussions and collaboration to be respectful, useful, and safe for everyone.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss ideas and code rather than attacking people.
- Explain disagreements calmly and accept good-faith feedback.
- Respect privacy; do not publish another person's personal information or private project data.
- Keep communication focused on the project and appropriate for a public technical community.

## Unacceptable behavior

Harassment, discrimination, threats, insults, deliberate intimidation, unwanted sexual attention, doxxing, and repeated disruptive conduct are not acceptable. Publishing private information without consent or using project channels to threaten or target another person is also prohibited.

## Maintainer responsibilities

Project maintainers may remove or edit content, close discussions, or restrict participation when needed to address harmful behavior. They should explain moderation decisions when practical and handle reports with care.

## Reporting and enforcement

For conduct that needs maintainer attention, contact the project owner through the GitHub account [@brajesh31](https://github.com/brajesh31). Do not use a public issue to share sensitive details. Include links, dates, and relevant context where possible. Reports will be reviewed and handled as privately as the available GitHub tooling permits.

Maintainers will consider the impact, context, and pattern of conduct when deciding on an appropriate response. Retaliation against someone who raises a concern in good faith is not acceptable.

## Scope

This code applies in project repositories, issues, pull requests, review comments, and other spaces where someone is representing the CodeTracker project.
